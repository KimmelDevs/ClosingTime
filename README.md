# ClosingTime

A first-person horror game set in the Halvorsen Galleria, a dead mall frozen on Halloween night, 1989.
Something in the mall only stops moving when your flashlight is on it.

## Godot version (main)

The game lives in `godot/` (Godot 4.7).

1. Open Godot 4.7, click **Import**, pick `godot/project.godot`.
2. Press **F5** to play.

Editing:
- **The mall**: open `scenes/mall.tscn`. Every prop, fuse, note, hiding spot, light and mannequin is a node you can move.
  Walls are a GridMap (`scenes/mall_walls.tres`): select `Navigation/Structure/Walls` and paint.
  The navmesh re-bakes when the game starts, so moved props are respected.
- **Rebuilding the mall from scratch** (overwrites `mall.tscn` edits):
  `Godot --headless --path godot --script res://tools/build_mall.gd`
- **3D models**: every model is a `.blend` in `blender/models/`. Edit in Blender 5.x, then
  File > Export > glTF 2.0 (.glb) into `godot/models/` with the same name. To regenerate them all:
  `blender -b -P blender/build_models.py`
- **Textures**: PNGs in `godot/textures/` (generated by `tools/make_textures.py`).
- **Sounds**: WAVs in `godot/audio/` (generated by `tools/make_audio.py`). Replace any file to change a sound.
- **Story text**: `godot/scripts/notes.gd`.
- **The enemy**: `godot/models/iris_running.fbx` (Mixamo character + run cycle), logic in `godot/scripts/iris.gd`.

Screenshot tour for development: `Godot --path godot -- --autotest` (writes `godot/screenshots/`).

## Web version (original prototype)

Double-click `Play Closing Time.bat` (needs Python). It serves `closing-time.html` on a local port.

## Controls

WASD move · Mouse look · Shift run · F flashlight · E interact / hide · hold C wind the flashlight · Space hold breath · Esc pause
Controller: sticks move/look · A interact · X flashlight · Y wind · RT run · LT/B hold breath · Start pause
