# ClosingTime

A first-person horror game set in the Halvorsen Galleria, a dead mall frozen on Halloween night, 1989.
Something in a red dress only stops moving when your flashlight is on it.

## Play

Double-click `Play Closing Time.bat` (needs Python). It starts a local server and opens
`http://localhost:8765/closing-time.html`. Opening the HTML file directly won't load the 3D model.

## Controls

WASD move · Mouse look · Shift run · F flashlight · E interact · Esc pause
